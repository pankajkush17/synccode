Part 10Running it on your machine

A step-by-step checklist for this Mac. Your machine already has Node, pnpm, Postgres 14 and Redis installed through Homebrew, and the project's .env file is already written.

10.1 Check the prerequisites

node -v            # needs v22 or newer            (you have v26)
pnpm -v            # any recent version            (you have v12)
psql --version     # Postgres 14 or newer          (you have 14)
redis-cli ping     # should print PONG

If any is missing: brew install node pnpm postgresql@14 redis.

10.2 Start the two services

brew services start postgresql@14      # starts Postgres now and at every login
brew services start redis              # Redis (already running on your machine)
brew services list                     # both should say "started"

10.3 Create the databases

createdb synccode                      # the app's database
createdb synccode_test                 # a separate one for the tests

Homebrew's Postgres lets your macOS user connect without a password, which is why the connection address below contains no username or password.

10.4 Install the project's libraries

cd ~/Documents/"Pankaj Personal"/syncCode
pnpm install

10.5 Check the settings file

The file .env in the project root already exists. It should contain:

DATABASE_URL=postgres://localhost:5432/synccode
REDIS_URL=redis://localhost:6379
EDIT_SECRET=<64 hex characters, already generated for you>
PORT=4000
LOG_LEVEL=info
ALLOWED_ORIGINS=http://localhost:3000
NEXT_PUBLIC_SYNC_WS_URL=ws://localhost:4000
SYNC_HTTP_URL=http://localhost:4000

If you ever need a new secret: openssl rand -hex 32. Changing it invalidates the edit links of existing rooms.

10.6 Create the tables

pnpm db:migrate                        # prints "migrations applied"

10.7 Start everything

pnpm dev

This starts the sync server on port 4000 and the website on port 3000. Leave the terminal open. Then visit:

AddressWhat it is
http://localhost:3000The landing page
http://localhost:3000/engineeringThe visual explanation of the backend
http://localhost:4000/readyzThe sync server's health check

Press Ctrl-C in the terminal to stop both.

10.8 Things to try, in order

  1. Two people. Start a room. Copy the address into a private window. Type in both.
  2. View only. Press Share, choose "View only", open that link in a third window. Try to type there.
  3. Reconnection. Stop the server (Ctrl-C). The amber banner appears; keep typing. Start it again with pnpm dev. Your text is saved.
  4. Persistence. Close every window. Reopen the room's link. The text is still there. Find it in the database with the queries from section 7.7.
  5. Watch the wire. Run redis-cli psubscribe 'room:*' and type.
  6. Two servers. In two terminals: 
    PORT=4000 NODE_NAME=sync-a pnpm dev:sync
PORT=4001 NODE_NAME=sync-b pnpm dev:sync
    Then, in a third: SYNC_URLS=ws://localhost:4000,ws://localhost:4001 pnpm load-test. It reports the delivery times and whether all fifty copies converged.
  7. Seed some rooms. pnpm seed prints links to three rooms with code already in them.

10.9 Run the tests

export TEST_DATABASE_URL=postgres://localhost:5432/synccode_test
export TEST_REDIS_URL=redis://localhost:6379

pnpm test            # 107 unit, integration and two-server tests
pnpm lint            # code style
pnpm typecheck       # TypeScript

For the browser tests, keep pnpm dev running in one terminal and, in another:

pnpm --filter @synccode/web exec playwright install chromium    # once
pnpm test:e2e

If you leave out the two TEST_… variables, the tests try to start their own Postgres and Redis in Docker instead, which needs Docker Desktop to be running.

10.10 The Docker alternative

If Docker Desktop is running, one command starts the whole multi-server setup without using your local Postgres or Redis:

docker compose -f docker/docker-compose.yml up --build

Then open http://localhost:3000. This path was written but not run on this machine, because Docker was not running when the project was built.

10.12 Troubleshooting

SymptomCause and fix
cannot reach Postgres or ECONNREFUSED …:5432Postgres is not running. brew services start postgresql@14.
database "synccode" does not existRun createdb synccode, then pnpm db:migrate.
relation "rooms" does not existTables not created yet. pnpm db:migrate.
Invalid configuration: EDIT_SECRET…The secret must be exactly 64 hex characters. Generate one with openssl rand -hex 32.
ECONNREFUSED …:6379Redis is not running. brew services start redis.
EADDRINUSE :::4000 (or 3000)Something is already using the port. Find it with lsof -i :4000 and stop it, or stop an earlier pnpm dev.
"Could not start a room" on the landing pageThe sync server is not running or not reachable. Check curl localhost:4000/readyz.
Editor shows "This edit link is not valid"The room was created with a different EDIT_SECRET. Start a new room.
Stuck on "Joining room"The page loaded but the WebSocket cannot connect. Check the sync server is up and NEXT_PUBLIC_SYNC_WS_URL is correct.
Playwright: "Executable doesn't exist"Install the test browser: pnpm --filter @synccode/web exec playwright install chromium.
