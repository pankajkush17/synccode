Before you startHow to read this guide

This guide assumes you know a little programming and nothing about real-time systems. It builds up in layers: first what the product does, then the ideas behind it, then the code, then the databases, and finally how to run it.

You do not need to read it in one sitting. Parts 1 and 2 give you the mental model; if you only have an hour, read those. Parts 3 to 7 are the tour of the actual code and data. Part 10 is the setup checklist, which you can follow on its own.

Three kinds of coloured boxes appear throughout:

In plain wordsA short, jargon-free version of the idea that was just explained.
Why it is built this wayThe reasoning behind a design decision, the kind of thing an interviewer asks about.
Try itSomething you can run on your machine to see the idea for yourself.
